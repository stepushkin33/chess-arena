# Chess Arena

Онлайн-шахматы: React + Pixi.js, Nest.js, TypeScript и WebSocket. Пакеты организованы
как npm workspaces: `client`, `server`, `shared`. Используется **npm**, Node.js 22.12+.

## Бесплатно опубликовать на Render

Запускается один Web Service: Nest раздаёт клиент и обслуживает WebSocket на том же домене.
Готовый `render.yaml` позволяет использовать Blueprint. Ручные настройки:

| Поле           | Значение                                      |
| -------------- | --------------------------------------------- |
| Runtime        | Node                                          |
| Root Directory | Корень проекта (все три workspace)            |
| Build          | `npm ci --include=dev && npm run build`       |
| Start          | `npm start`                                   |
| Plan           | Free                                          |
| Health Check   | `/health`                                     |
| Environment    | `NODE_ENV=production`, `NODE_VERSION=22.23.4` |

Публичный адрес определяется автоматически из переменных Render.
[Пошаговое руководство, свой домен и устранение ошибок](docs/deployment.md).

## Разработка

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для телефона используйте показанный сетевой
адрес компьютера и ту же Wi-Fi сеть. Vite слушает все интерфейсы; фиксированный порт
не позволяет случайно перейти на другой проект. Nest запускается раньше клиента,
проверка готовности — `/health`. macOS должна разрешать Node входящие подключения.

Для проверки готовой сборки вне Render задайте публичный HTTP(S)-адрес в `PUBLIC_URL`,
при необходимости `PORT`, затем выполните `npm run build` и `npm start`.

## Возможности

- Разрешённые ходы, шах, мат, пат, обе рокировки, взятие на проходе, четыре превращения.
- Повторения и правила 50/75 ходов с отдельным заявлением ничьей.
- Классические SVG Cburnett, одинаковые на телефоне и компьютере; анимация ходов.
- Угрозы только в свой ход, история с названием фигуры, списки взятых фигур.
- Подтверждение сдачи, предложение и отзыв ничьей, новая партия с ответом соперника.
- Имя при входе, инвайт-ссылки, экран занятой комнаты, мобильная компоновка, гостевой счёт.

## Проверки

```bash
npm run format:check
npm run lint
npm test
npm run build
npm run test:smoke
npm run test:dev
```

Smoke запускает собранный Nest на случайном порту и останавливает собственный процесс.
Проверяет HTML, прямую ссылку комнаты, ресурсы, health, Origin, реальный WebSocket
двух игроков, отклонение третьего, ход/взятие, ничью/отзыв, реванш и счёт.

`test:dev` отдельно запускает Nest и Vite на временных портах: проверяет 100 разрывов
во время WebSocket-handshake, обмен ходом и автоматический повторный вход настоящего
клиентского транспорта. Ошибки недоступного Nest остаются видимыми; ожидаемые EPIPE /
ECONNRESET со стороны закрывшегося браузера выводятся коротким информационным сообщением.
