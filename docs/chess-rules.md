# Проверка шахматных правил

Источник правил — [FIDE Laws of Chess, редакция 2023](https://handbook.fide.com/chapter/e012023).
В приложении классические шахматы без контроля времени. Положения о судьях, физическом
касании фигур и турнирных наказаниях не моделируются браузерным интерфейсом.

## Что проверяется

| Правило                                        | Реализация и проверка                                                               |
| ---------------------------------------------- | ----------------------------------------------------------------------------------- |
| Очерёдность хода, свои/чужие фигуры            | `RoomGame.move` и `makeMove`, серверные тесты                                       |
| Геометрия всех шести фигур, преграды           | `move-generation.ts`, контрольные деревья ходов                                     |
| Пешка вперёд, двойной ход, диагональное взятие | Отдельные регрессионные позиции                                                     |
| Шах, связки, двойной шах, соседство королей    | Симуляция каждого хода и `isInCheck`                                                |
| Рокировка                                      | Наличие ладьи, сохранённые права, пустой путь, проверка атак на клетки короля       |
| Взятие на проходе                              | Только сразу после двойного хода; проверка вскрытого шаха, запись взятой пешки      |
| Превращение                                    | Четыре варианта обоих цветов, включая взятие на последней горизонтали               |
| Мат/пат                                        | Отсутствие разрешённых ходов с шахом/без шаха                                       |
| Повторение                                     | Ключ учитывает очередь, права рокировки и только доступное легальное en passant     |
| 3 повторения / 50 ходов                        | Право игрока в свой ход заявить ничью, включая заявленный следующий ход             |
| 5 повторений / 75 ходов                        | Автоматическое завершение; мат имеет приоритет на последнем ходе                    |
| Недостаток материала                           | Короли; король с одним конём/слоном; только одноцветные слоны, включая превращённые |
| Сдача                                          | Однократный счёт побед; голому королю победа не присуждается                        |
| Ничья по соглашению                            | После первого хода обоих игроков; предложение, отказ, согласие, отзыв               |

Подсветка угроз показывает легальные взятия собственных фигур соперником. Для шаха и
рокировки применяется отдельная карта атак: связанная фигура по-прежнему атакует клетки.

## Регрессионные исправления

- Взятие на проходе теперь записывает `captured: 'p'` и отражается под доской.
- Фиктивное поле en passant не делает одинаковые позиции различными.
- Статус завершённой игры блокирует новые ходы и повторную выдачу победы.
- Входные координаты должны быть целыми числами 0–7; спецфлаги клиента не доверяются.
- Ничьи по заявлению отделены от автоматических ничьих; причина показывается в интерфейсе.
- У чёрных ранги доски подписываются по реальным клеткам, независимо от ориентации.

## Контроль генератора

`rules-regression.test.ts` использует стандартные perft-позиции, также применяемые
в [тестах Stockfish](https://github.com/official-stockfish/Stockfish/blob/master/tests/perft.sh).
Perft считает дерево легальных ходов, а не оценку позиции:

| Позиция                   | Глубина, полуходы | Число листьев       |
| ------------------------- | ----------------- | ------------------- |
| Начальная                 | 3 / 4             | 8 902 / 197 281     |
| Kiwipete                  | 1 / 2 / 3         | 48 / 2 039 / 97 862 |
| Ладейно-пешечный эндшпиль | 3                 | 2 812               |

## Границы реализации

Контрольные деревья и регрессионные позиции существенно повышают уверенность, но не
доказывают корректность для всех достижимых позиций. Автоматическая проверка dead position
ограничена перечисленными комбинациями материала: универсального решателя закрытых
пешечных крепостей и других произвольных позиций, где мат невозможен любой серией ходов,
здесь нет. Для такого редкого случая остаётся предложение ничьей.

Счёт — гостевые победы, а не турнирный рейтинг. Часы и проигрыш по времени не реализованы.
История хранит подробную координатную нотацию; экспорт SAN/PGN не заявляется.
