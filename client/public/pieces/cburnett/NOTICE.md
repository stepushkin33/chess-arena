# Cburnett chess pieces

Artwork by Colin M. L. Burnett (User:Cburnett), distributed under GNU GPL version 2
or any later version. See LICENSE.txt. The artwork files are separate from the
application source code. SVG sources come from the Cburnett set distributed by
Lichess. The two king files have explicit width/height attributes added for Pixi's
SVG loader; drawing paths are unchanged. SVGs are rasterized at high resolution at runtime.

Source: https://github.com/lichess-org/lila/tree/master/public/piece/cburnett
